# 墨屿博客 - 前端B（文章管理模块）

这是墨屿博客系统的前端文章管理模块，包含文章列表、详情、编辑器、管理后台等页面。

## 技术栈

- React 19 + TypeScript 6
- Vite 8
- react-router-dom 7
- zustand 5
- axios
- react-markdown
- dompurify

## 功能

- 文章列表（带筛选和分页）
- 文章详情（Markdown 渲染）
- 文章编辑器（Markdown 编辑和预览）
- 我的文章管理
- 管理后台（仪表盘、文章管理、评论审核、用户管理、分类标签管理）

## 本地运行

```bash
npm install
npm run dev
```

默认地址：`http://localhost:5173`

## 合并说明

本仓库需要与前端A（认证模块）合并后才是完整的前端系统。
