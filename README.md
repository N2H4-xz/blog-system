# 墨屿博客 - 前端A（认证模块）

这是墨屿博客系统的前端认证模块，包含首页、登录、注册、个人资料等页面。

## 技术栈

- React 19 + TypeScript 6
- Vite 8
- react-router-dom 7
- zustand 5
- axios

## 功能

- 首页展示
- 用户登录
- 用户注册
- 个人资料页
- JWT 认证管理

## 本地运行

```bash
npm install
npm run dev
```

默认地址：`http://localhost:5173`

## 合并说明

本仓库需要与前端B（文章管理模块）合并后才是完整的前端系统。
